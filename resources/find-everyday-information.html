For educators · Teaching notes

Model common interface cues, including search icons and information cards. These examples are simulations; transfer the practice to an approved, real website or app using current information.

Use the Guided setting for initial practice and Independent when prompts can be faded. Observe whether the learner can select the appropriate app and locate the requested information.

Fictional, offline practice. No personal information is requested or transmitted. Completing these tasks does not establish independent use of a real-world service.
